# CAGE Docs

Public documentation site for the closed-source **CAGE** language and runtime.

This repository contains documentation, tutorials, examples, and deployment/build automation only. The CAGE compiler/runtime implementation remains private.

## Included

- Next.js + TypeScript/TSX static export
- 100+ generated documentation routes
- Animated tutorial routes
- Mobile-first responsive docs UI
- `examples/` CAGE programs
- Netlify deployment configuration
- ZIP-only sync/build GitHub Actions workflow
